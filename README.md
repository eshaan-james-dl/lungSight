## Introduction 👋

lungSight is a sophisticated AI-powered application designed for the analysis of chest X-rays. It aims to assist healthcare professionals by providing automated detection of various pathologies. The system is built with a clear separation between a robust FastAPI backend, responsible for model inference and explainability, and a user-friendly Streamlit frontend for seamless interaction.

This project focuses on identifying five key thoracic conditions: Cardiomegaly, Edema, Consolidation, Atelectasis, and Pleural Effusion. It not only predicts the likelihood of these conditions but also provides visual explanations through Grad-CAM heatmaps and textual explanations generated by a large language model, making the AI's decision-making process more transparent.

---

## Features ✨

*   **Multi-label Pathology Classification:** Detects the presence of Cardiomegaly, Edema, Consolidation, Atelectasis, and Pleural Effusion in chest X-rays.
*   **Probability Scores:** Provides confidence scores for each detected pathology.
*   **Grad-CAM Explainability:** Generates class-specific heatmaps to visualize the regions in the X-ray that influenced the model's prediction.
*   **AI-Generated Explanations:** Offers concise, plain-language explanations of the Grad-CAM output, contextualized with model scores.
*   **Hugging Face Model Integration:** Automatically downloads model artifacts from Hugging Face upon startup.
*   **Docker Support:** Includes a Dockerfile for containerized deployment.
*   **Dual Entry Points:** Offers both a FastAPI backend and a Streamlit frontend.

## Installation 🚀

### Prerequisites

*   Python 3.11+
*   Docker (for containerized deployment)

### Backend Installation (FastAPI)

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/eshaan-james-dl/lungSight.git
    cd lungSight
    ```

2.  **Install backend dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Setup Environment Variables:**
    Ensure you have your Hugging Face repository ID and revision set if you are not using the defaults (`HF_REPO_ID`, `HF_REVISION`). For LLM explanations, set `LLM_API_KEY` and optionally `LLM_BASE_URL` and `LLM_MODEL`.

    Example `.env` file (create one in the root directory):
    ```dotenv
    HF_REPO_ID=eshaanjamesdl/lungsight
    HF_REVISION=main
    LLM_API_KEY=your_llm_api_key
    LLM_BASE_URL=https://api.groq.com/openai/v1
    LLM_MODEL=qwen/qwen3.6-27b
    ```

4.  **Run the FastAPI server:**
    ```bash
    uvicorn app.main:app --reload
    ```

### Frontend Installation (Streamlit)

1.  **Navigate to the frontend directory:**
    ```bash
    cd frontend
    ```

2.  **Install frontend dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Set the API URL (if not running locally):**
    By default, the frontend looks for the API at `http://localhost:8000`. If your backend is hosted elsewhere, set the `LUNGSIGHT_API_URL` environment variable.

    For example, in PowerShell:
    ```powershell
    $env:LUNGSIGHT_API_URL="http://your_backend_ip:8000"
    ```

4.  **Run the Streamlit app:**
    ```bash
    streamlit run app.py
    ```

### Docker Installation

Build and run the Docker image:

```bash
docker build -t lungsight .
docker run -p 8000:8000 lungsight
```

Note: Ensure environment variables for Hugging Face and LLM are configured as needed. The Dockerfile copies `requirements.txt` and installs dependencies.

## Usage 💡

### Running the Application

1.  **Start the FastAPI backend:** Follow the backend installation steps.
2.  **Start the Streamlit frontend:** Follow the frontend installation steps.

### Analyzing an X-ray

1.  **Upload Image:** In the Streamlit app, navigate to the "Analyze X-ray" tab. Upload a chest X-ray image (PNG, JPG, JPEG, WEBP).
2.  **Analyze:** Click the "Analyze X-ray" button. The frontend will send the image to the FastAPI backend.
3.  **View Predictions:** The results will display probabilities for each of the five pathologies.
4.  **Generate Explainability:** Select a pathology from the dropdown and click "Generate Grad-CAM." You can choose to generate an AI explanation alongside the heatmap.

### API Endpoints (FastAPI Backend)

*   **`GET /health`**: Checks the status of the backend and model loading.
    *   **Response:** `{"status": "ok", "model_loaded": true, "llm_configured": false}`

*   **`POST /predict`**: Predicts pathologies for an uploaded X-ray image.
    *   **Request Body:** `multipart/form-data` with a file field named `file`.
    *   **Response:** `{"predictions": {"Cardiomegaly": 0.1, "Edema": 0.05, ...}}`

*   **`POST /gradcam`**: Generates a Grad-CAM heatmap for a specified disease, optionally with an AI explanation.
    *   **Request Body:** `multipart/form-data` with a file field named `file`.
    *   **Query Parameters:**
        *   `disease` (optional): The pathology to generate Grad-CAM for (e.g., "Cardiomegaly"). Defaults to the highest predicted class.
        *   `explain` (optional, boolean): If true, returns a JSON object with the explanation. If false, returns the raw PNG image.
    *   **Response (explain=true):**
        ```json
        {
          "label": "Cardiomegaly",
          "probability": 0.85,
          "explanation": "...AI generated explanation...",
          "heatmap_image_base64": "...base64 encoded image..."
        }
        ```
    *   **Response (explain=false):** PNG image stream.

## API Reference 🌐

### Backend API (FastAPI)

The backend exposes the following endpoints:

*   **`GET /health`**
    *   **Description:** Health check endpoint.
    *   **Returns:** JSON object indicating the status of the service and model.

*   **`POST /predict`**
    *   **Description:** Accepts an X-ray image and returns predictions for multiple pathologies.
    *   **Input:** `multipart/form-data` with `file`.
    *   **Output:** JSON with prediction probabilities for each class.

*   **`POST /gradcam`**
    *   **Description:** Generates a Grad-CAM heatmap and optionally an AI explanation.
    *   **Input:** `multipart/form-data` with `file`.
    *   **Query Parameters:** `disease` (string, optional), `explain` (boolean, optional).
    *   **Output:** JSON with explanation and base64 encoded heatmap (if `explain=true`), or raw PNG image (if `explain=false`).
